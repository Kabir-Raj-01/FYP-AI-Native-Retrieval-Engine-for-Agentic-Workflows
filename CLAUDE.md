## Project
**AI-Native Retrieval Engine for Agentic Workflows** — Final Year Project, BS(CS),
FAST-NUCES Karachi, Fall 2026 – Spring 2027.
Team: **Kabir Raj** (data, retrieval, controller-OFF direct path, cache, infra) ·
**Samay Kumar** (state, controller, reranking, evidence, stopping) · **Vishal Kothari**
(planner, API/client, LLM client, baselines, trajectory logging, evaluation, testing,
agent integration).

A standalone retrieval-control middleware service (Python, FastAPI) that sits between a
host RAG/agent application and a Qdrant backend.
- **Controller-OFF (direct):** one-shot retrieval, no state.
- **Controller-ON:** a stateful loop over task state S_t:
  plan → select action → cache/REUSE gate → retrieve → rerank → update evidence →
  continue / replan / stop.
- Output is an **EvidenceBundle** (evidence + trace summary + stop reason).
  The engine **never generates the final answer** — the host app (or eval harness) does.

## Non-negotiable rules
1. Python 3.11. Type hints everywhere; `mypy --strict` must pass on `engine/`.
2. Shared data = Pydantic v2 models defined ONLY in `engine/state/models.py`
   (HTTP-only wrappers in `engine/api/schemas.py`). No raw dicts across module boundaries.
3. Concrete implementations are chosen only in `engine/factory.py`, from config.
4. No literal thresholds, weights, model names, paths or k values in code. Every one is a
   config key. Adding a key = update `configs/base.yaml` + `docs/CONFIG_SCHEMA.md` +
   `EngineConfig` in the same PR.
5. Every LLM call goes through `engine/llm`. Never import a provider SDK anywhere else.
6. Every embedding goes through `engine/embeddings`. It must be the same model as the index.
7. The field-ownership matrix in `STATE_SPEC.md` is binding. In particular the planner
   never writes evidence; only the EvidenceManager writes `evidence` and resolves gaps.
8. The cache is task-local. Every lookup is keyed by `task_id`; a test proves there are
   no cross-task hits.
9. The controller policy is deterministic code (rules + utility), never an LLM call.
10. Retrieved text is untrusted data: wrapped in delimiters, never placed in the system
    role, never obeyed (`SECURITY.md`).
11. Contracts (STATE_SPEC models, API_CONTRACT, trace schema) change only with an ADR.
12. Never tune anything on the test split. Keys marked **Frozen** in CONFIG_SCHEMA change
    only via a new ADR.
13. Every run writes a manifest. Every decision affecting actions, cache or stopping is
    logged (`OBSERVABILITY.md`).
14. Tests ship with every change. Unit tests use fakes (no network, no running Qdrant). Never
    weaken or delete a test to make it pass without saying so explicitly.
15. Library versions are pinned. Check `LIBRARY_NOTES.md` before using LangGraph, Qdrant,
    sentence-transformers or fastembed APIs; if unsure, read the installed package source
    or ask. Do not code from memory of older versions.
16. Out-of-scope items (PRD.md) are flagged, not built.
17. Windows only. Every command is PowerShell on Windows 10/11; do not add build, setup
    or container files for any other operating system.

## Session protocol (Claude Code)
**Start:** read the `TASKS.md` item and its governing doc(s). Restate goal + acceptance
criteria. Propose a plan (files to touch, tests to add). Wait for approval if the change
touches more than one module or any contract.
**During:** small steps; run the unit tests and `ruff check .`; report real output. Never
claim a command passed without running it.
**End:** summarize changes; list doc updates made or needed (TASKS.md status,
LIBRARY_NOTES.md gotchas, ARCHITECTURE.md change log, new ADR); propose a commit message
(Conventional Commits, see CONTRIBUTING.md).
